# 칸칸 (KanKan)

바탕화면에 이름 붙은 색 구역을 깔아서, 폴더·파일을 용도별로 한눈에 구분하는 Windows 앱.
구역은 바탕화면에 붙어 있어 다른 창 아래에 깔리고, `Win+D`에도 사라지지 않으며, 재부팅해도 그 자리에 있다.

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 새 영역 | 트레이 아이콘 메뉴 → 새 영역 만들기 (또는 트레이 아이콘 더블클릭) |
| 옆에 하나 더 | 제목 바 `+` — 같은 크기·다른 색으로 옆 빈 자리에 (띄운 메모에서 누르면 새 메모도 띄운 창으로) |
| 이동 / 크기 조절 | 제목 바 드래그 / 테두리·모서리 드래그 |
| 위치·크기 고정 | 제목 바 📌 — 누를 때마다 자유 → 고정 → (메모 모드만) 창으로 띄우기 → 자유 |
| 메모를 브라우저 위에 띄우기 | (메모 모드) 📌를 고정 다음 단계(침 없는 핀)로 — 바탕화면에서 떨어진 보통 창이 되어 다른 창 위로 올라오고, 작업 표시줄·`Alt+Tab`으로 오갈 수 있다. 이동·크기 조절은 자유 |
| 이름 바꾸기 | 제목 더블클릭, 또는 `⋯` → 이름 바꾸기 |
| 색·배경 진하기 | `⋯` → 색 변경 / 배경 진하기 |
| 스티커 메모로 쓰기 | `⋯` → 메모 모드로 바꾸기 — 영역 안 아이콘은 메모 아래에 그 자리 그대로 있다가, 영역 모드로 돌아오면 다시 보임 (파일은 그대로) |
| 저장된 노트 보기·불러오기 | (메모 모드) `⋯` → 노트 목록 — 클릭하면 옆에 새 메모 영역으로 열림 (지금 메모는 그대로, 띄운 메모에서 열면 새 메모도 띄운 창), `+ 새 노트`, 우클릭 → 삭제 |
| 지운 메모 영역 되살리기 | 노트 목록에서 "지운 영역" 표시가 있는 노트 클릭 — 제목·색·위치·크기 그대로 원래 자리에 다시 생김 (글 없는 메모를 지웠으면 남지 않음) |
| 글자 크기·행간 | (메모 모드) `⋯` → 텍스트 설정 — 메모 영역마다 따로 |
| 붙여넣기 | (메모 모드) 다른 프로그램에서 복사한 글은 서식 없이 글자만, 엑셀·워드 표는 칸을 공백으로 맞춘 글자로 들어간다. 메모끼리 복사하면 서식 그대로 |
| 사진 넣기 | (메모 모드) 사진이나 사진 파일을 복사해 붙여넣기 — 원본 크기·용량과 상관없이 가로 10cm(JPEG)로 맞춰진다. 사진은 `%APPDATA%\KanKan\images`에 따로 저장 |
| 모두 숨기기, 자동 실행 끄기, 종료 | 트레이 아이콘 메뉴 |

메모 모드 단축키: `Ctrl+B` 굵게 · `Ctrl+Shift+S` 취소선 · `Ctrl+Shift+C` 체크리스트 · `Ctrl+Shift+L` 글머리 기호

## 다른 PC에 설치 (배포 zip)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package.ps1     # → dist\KanKan-<버전>.zip
```

.NET 런타임을 포함한 단일 실행 파일이라 받는 PC에는 아무것도 설치할 필요가 없다 (Windows 10/11 64비트).
받는 PC에서는 압축을 풀고 `설치.cmd` 더블클릭 → 설치·자동 실행 등록·시작 메뉴 바로가기 후 실행. 제거는 `제거.cmd`.
서명되지 않은 exe라 SmartScreen 경고가 뜨면 [추가 정보] → [실행].

## 개발 PC에서 설치 / 업데이트 / 제거

.NET 8 SDK가 필요하다 (`winget install Microsoft.DotNet.SDK.8`).

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1     # 소스에서 빌드해 설치·업데이트
powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1   # 제거 (-RemoveData 를 붙이면 영역 데이터까지)
```

두 방식 모두 실제 설치 단계는 `scripts\install-app.ps1` 하나를 같이 쓴다.

- 프로그램: `%LOCALAPPDATA%\Programs\KanKan`
- 영역 데이터·로그: `%APPDATA%\KanKan\zones.json`, `kankan.log`

## 개발

```powershell
dotnet build                     # 빌드
dotnet test                      # 단위 테스트
src\KanKan\bin\Debug\net8.0-windows\KanKan.exe   # 개발 빌드 실행 (설치본이 돌고 있으면 먼저 트레이에서 종료)
scripts\make-icon.ps1            # 앱 아이콘 다시 만들기
```

구조와 바탕화면 고정 방식의 기술 메모는 [PLAN.md](PLAN.md) 참고.
